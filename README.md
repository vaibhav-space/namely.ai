# namely.ai

Stop naming things like `doStuff()`. Get AI-powered variable, function, and class names your future self won't curse you for.

## About

namely.ai is a local-first AI naming tool for developers that generates perfect names based on your code context, tech stack, and personal preferences.

## Features

- **AI-Powered Naming**: Generate contextually perfect names for functions, variables, classes, and UI labels
- **Tech Stack Aware**: Personalized suggestions based on your specific technologies and frameworks
- **Multiple Naming Conventions**: Support for camelCase, snake_case, PascalCase, kebab-case, and SCREAMING_SNAKE_CASE
- **Local-First**: Your code and preferences stay on your machine
- **Developer Profiles**: Learns your coding style and preferences over time
- **Rejection Learning**: Improves suggestions by learning from rejected names

## Technologies

This project is built with:

- **Vite** - Fast build tool and dev server
- **TypeScript** - Type-safe JavaScript
- **React** - UI framework

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd namely.ai

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Build the application
npm run build

# Preview the production build
npm run preview
```

## Usage

1. **Set up your profile**: Configure your name, tech stack, and coding preferences
2. **Add your API key**: Configure your Google Gemini API key for AI-powered suggestions
3. **Start naming**: Paste your code or describe what you need to name
4. **Get suggestions**: Receive 5 contextually perfect naming suggestions
5. **Copy and use**: Click to copy names directly to your clipboard

## Development
